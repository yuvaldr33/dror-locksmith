# Perfectionist gate

Ship only what you would proudly put in the studio's portfolio.

## Score each dimension 1–10 with evidence
1. **Brief fit** — does it do exactly what the client needs, for their audience?
2. **Idea** — is there a memorable idea, or is it decoration?
3. **Craft** — spacing, typography, cut timing, sound, pixels, code quality. Look at the actual output (screenshots, extracted frames, rendered SVG), not the description of it.
4. **Emotion** — would the target customer feel something in the first 3 seconds?
5. **Conversion** — is the next action obvious and easy?
6. **Hebrew** — natural, correct, RTL right.
7. **Technical** — qa-inspector checklist passed with evidence.
8. **Honesty & compliance** — claims true, AI disclosed where needed, licences recorded.

## Rules
- Pass = every dimension ≥ 9. Otherwise list fixes as: problem → location → why it matters → exact fix, and send back to the owning agent.
- Compare against a real best-in-class reference, not against the previous draft.
- "Done" means checked, not assumed: if something could not be verified, say so.
- Track recurring failures in `_ai-studio/quality-log.md` and update the relevant agent's instructions so the mistake does not repeat.
