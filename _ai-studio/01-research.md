## חלק ב׳ – המחקר על כל רעיון

### רעיון 1: אתרים ברמה "פסיכית"

**מה מבדיל אתר שכל בעל עסק רוצה כזה?** לא "יותר אפקטים". אתרים שזוכים בפרסים (Awwwards וכו׳) בנויים על:
1. **כיוון אמנותי לפני קוד** – קונספט ויזואלי, טיפוגרפיה, פלטת צבעים, ו"שפת תנועה" מוגדרים מראש.
2. **תנועה עם ריסון** – GSAP + ScrollTrigger לכוריאוגרפיה של הגלילה, Lenis לגלילה חלקה, Three.js/WebGL רק איפה שזה משרת את הסיפור.
3. **נכסים מקוריים** – תמונות ווידאו שנוצרו במיוחד למותג (לא סטוק). כאן נכנסים כלי ה־AI של רעיונות 2–3.
4. **מהירות ונגישות** – טעינה מהירה בנייד, חלופה סטטית למכשירים חלשים, תמיכה ב־reduced-motion. אתר יפה ואיטי מפסיד לקוחות.
5. **המרה** – כפתור וואטסאפ/חיוג במקום הנכון, הוכחה חברתית, טופס קצר. היופי מביא את הלקוח, ההמרה מביאה את הכסף.

**תהליך העבודה המומלץ (Pipeline):**
| שלב | מי עושה | כלי |
|---|---|---|
| 1. בריף ואסטרטגיה | Claude | שאלון לקוח, ניתוח מתחרים |
| 2. מודבורד והשראה | ChatGPT + אתה | Awwwards, Godly, תמונות קונספט ב־ChatGPT |
| 3. כיוון אמנותי כתוב | Claude | מסמך: טיפוגרפיה, צבעים, תנועה |
| 4. נכסים ויזואליים | "חברים" | תמונות/וידאו מקוריים (ראה רעיון 2) |
| 5. בנייה | Claude Code | Next.js/Astro + GSAP + Lenis + Three.js |
| 6. ביקורת עוינת | Codex | `/codex:adversarial-review` |
| 7. בדיקות | Claude | Lighthouse, מובייל, RTL, נגישות |
| 8. העלאה לאוויר | Claude | Vercel / Netlify / GitHub Pages |

**הטריק העסקי:** "דמו לפני מכירה" – בונים לבעל העסק גרסת הדגמה של האתר שלו *לפני* הפגישה. כשהוא רואה את העסק שלו בעיצוב כזה – המכירה כמעט סגורה. עם AI זה לוקח שעות, לא שבועות.

**איפה התקרה האמיתית:** אני יכול להגיע לרמה גבוהה מאוד בקוד. הפער ל"פסיכי" הוא כמעט תמיד **טעם ונכסים** – ולכן העין שלך + נכסים מקוריים הם מה שסוגר את הפער.

### רעיון 2: פרסומות ברמת טלוויזיה

**המצב בשטח (אוקטובר 2026):** אפשר להגיע לקליפים קולנועיים, אבל **לא בלחיצה אחת**. פרסומת טובה היא עשרות שוטים קצרים (5–15 שניות כל אחד), שנוצרים, נבחרים ונערכים.

**כלי הווידאו המובילים כרגע:**
| כלי | חוזקה | חולשה |
|---|---|---|
| **Google Veo 3.1** | ריאליזם ופיזיקה, אודיו מסונכרן, עד 4K | שוטים קצרים (~8 שניות, ניתן להאריך) |
| **Kling 3.0** | תנועה אנושית טבעית, עד 15 שניות, יחס מחיר/איכות | ממשק בעיקר בסינית |
| **Runway Gen-4.5** | שליטה ועריכה, כלי הפקה | רזולוציה נמוכה יותר (אפסקייל) |
| **Seedance 2.0 (ByteDance)** | מוזכר כחזק במיוחד לתוכן פרסומי | תקרה של 2K |

**Pipeline לפרסומת:**
1. **אסטרטגיה ותובנה** (Claude) – מי הלקוח, מה הכאב, מה הרגש. הוק ב־3 השניות הראשונות.
2. **תסריט + סטוריבורד מילולי** (Claude, ChatGPT מבקר) – שוט אחר שוט, זווית, תאורה, תנועת מצלמה.
3. **פריימים מרכזיים** (ChatGPT image / Nano Banana / Flux / Midjourney) – קודם תמונה, אחר כך מנפישים. זה הסוד לעקביות.
4. **הנפשה לווידאו** (Veo / Kling / Runway) – image-to-video מהפריימים.
5. **קול** (ElevenLabs – כבר מחובר! לעברית: מודל v3 עם קוד שפה `he`).
6. **מוזיקה** (Suno / ElevenLabs Music).
7. **עריכה** (DaVinci Resolve / Premiere / CapCut) + אפסקייל (Topaz) + **טקסט בעברית מוסף בעריכה** – כלי הווידאו עדיין חלשים בכתב עברי.
8. **גרסאות** – 9:16 לרילס/טיקטוק, 16:9 ליוטיוב/טלוויזיה, 1:1 לפיד.

**על "רגשי/מניפולטיבי":** שכנוע רגשי הוא לב הפרסום וזה לגיטימי לגמרי – סיפור, הזדהות, דחיפות אמיתית, הוכחה חברתית, לפני/אחרי. מה שלא נעשה: **הטעיה** – המלצות מזויפות, הבטחות שקריות, דחיפות מומצאת. זה גם אסור בחוק הגנת הצרכן בישראל, גם מסכן את חשבונות הפרסום (Meta/Google חוסמים), וגם הורס מוניטין של סוכנות חדשה. המטרה: פרסומת שמזיזה רגשית *ואמיתית* – זה מה שמחזיק.

**איפה התקרה:** 85–90% מרמת הפקה מסחרית אפשרי היום בתקציב קטן. ה־10% האחרונים = עורך טוב, סאונד מקצועי, וסבלנות לייצר הרבה גרסאות ולבחור את הטובה.

### רעיון 3: דמויות AI כפרזנטורים

**שני סוגי צרכים, שני סוגי כלים:**
| צורך | כלי | הערה |
|---|---|---|
| **פרזנטור מדבר למצלמה** (טוקינג הד, הסבר מוצר) | **HeyGen** (Avatar IV/V), Synthesia | הכי עקבי, ליפסינק טוב, רב־לשוני |
| **דמות בסצנות קולנועיות** (אותה דמות בחוף, במשרד, ברחוב) | **Higgsfield (Soul ID)**, LoRA מותאם ב־Flux/Stable Diffusion, תמונות עם רפרנסים מרובים | עדיין יש "סחף" – שינויים קטנים בפנים בין קליפים |

**השיטה ליצירת דמות עקבית:**
1. **תנ״ך הדמות** (Claude) – שם, גיל, אופי, סגנון לבוש, ערכים, איך היא מדברת. דמות עם אישיות מוכרת יותר.
2. **Character Sheet** – 20+ תמונות של אותה דמות: חזית, פרופיל, הבעות, תאורות.
3. **אימון זהות** – Soul ID / LoRA על התמונות.
4. **קול קבוע** – קול ייעודי ב־ElevenLabs שנשאר אותו דבר לתמיד.
5. **אווטאר מדבר** – העלאה ל־HeyGen לתוכן מדבר.
6. **בקרת איכות** – כל תוצר נבדק מול ה־Character Sheet.

**משפטי וחובה:**
- **לא** ליצור דמות שדומה לאדם אמיתי (סלבריטי או לא) – זכות לדמות ולשם.
- **סימון AI**: בניו יורק ובקליפורניה כבר יש חובת גילוי לפרפורמרים סינתטיים בפרסומות; ב־EU סעיף 50 של ה־AI Act; Meta מסמנת תוכן AI ריאליסטי. גם בישראל – פרזנטור AI שמציג "חוויה אישית" עם מוצר = המלצה מזויפת. מסמנים.
- **יתרון עסקי ענק:** דמות סינתטית מקורית = נכס שהלקוח *מחזיק*, בלי דמי פרזנטור, בלי שערוריות, זמינה 24/7.

## חלק ג׳ – איך מחברים אותי ל־ChatGPT

מסודר מהפשוט למתקדם:

### אפשרות 1 – "מתווך אנושי" (מתחילים כאן, היום)
אתה מעתיק את קובץ `02-chatgpt-briefing.md` לצ׳אט ב־ChatGPT, והוא מקבל את כל ההקשר. אחר כך מעבירים תשובות בינינו. פשוט, עובד, בלי התקנות.

### אפשרות 2 – זיכרון משותף בריפו GitHub (מומלץ מאוד)
שנינו קוראים מאותה תיקייה: אני קורא `CLAUDE.md`, Codex קורא `AGENTS.md`. שמים שם את המטרות, ההחלטות והסטטוס – וכל אחד מעדכן. ChatGPT יכול לקרוא את הריפו דרך חיבור GitHub שלו.

### אפשרות 3 – Codex בתוך Claude Code (החיבור הרשמי – הכי חזק לאתרים)
OpenAI שחררו במרץ 2026 תוסף רשמי (קוד פתוח) שמריץ את Codex מתוך Claude Code. במחשב שלך:
```
/plugin marketplace add openai/codex-plugin-cc
/plugin install codex@openai-codex
/codex:setup
```
דרישות: Node.js 18.18+, ומנוי ChatGPT (גם חינמי) או מפתח API של OpenAI.
פקודות עיקריות: `/codex:review` (ביקורת), `/codex:adversarial-review` (ביקורת עוינת), `/codex:rescue` (Codex לוקח משימה שנתקעה).
⚠️ בזמן ההשקה דווחה פרצת אבטחה שתוקנה – לוודא שמתקינים גרסה עדכנית.

### אפשרות 4 – הכיוון ההפוך: Claude בתוך Codex
Claude Code יכול לרוץ כשרת MCP (`claude mcp serve`) ו־Codex קורא לו. שימושי אם אתה עובד בעיקר ב־Codex.
(הערה: מקור אחד טוען שהפקודה `codex mcp-server` הוסרה בספטמבר 2026 לטובת התוסף – לא אימתתי מול OpenAI. התוסף מאפשרות 3 הוא הדרך הבטוחה.)

### אפשרות 5 – ChatGPT Developer Mode (מתקדם)
ב־ChatGPT: הגדרות → Apps & Connectors → Advanced → Developer Mode. שם מוסיפים שרת MCP חיצוני (HTTPS) – למשל אוטומציה ב־n8n שמפעילה את Claude דרך ה־API. OpenAI עצמם מזהירים שזה "חזק אבל מסוכן"; זמינות לפי מנוי משתנה.

### אפשרות 6 – אורקסטרציה מלאה (בהמשך, כשיש לקוחות)
n8n שמחבר Claude API + OpenAI API + Veo/Kling + ElevenLabs + HeyGen לצינור אחד: בריף נכנס → פרסומת יוצאת.

**ההמלצה שלי:** להתחיל עם 1+2 מיד, להתקין את 3 במחשב שלך לעבודת האתרים, ולבנות את 6 רק כשיש תהליך מוכח.
